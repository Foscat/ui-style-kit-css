# UI Style Kit CSS favicon pack

Generated for the UI Style Kit CSS demo site.

## Install

1. Keep this folder at `demo/assets/` for the checked-in demo site.
2. Paste the contents of `favicon-head-snippet.html` into a demo document that also has an `assets/` folder beside it.
3. If copying the pack into another public root, update the snippet paths to match that app's deployed base path.

## Included files

- `favicon.ico` with 16, 32, and 48 px embedded sizes
- `favicon.svg` scalable gradient icon
- PNG favicons: 16, 32, 48, 64, 96, 128, 256 px
- `apple-touch-icon.png` at 180 px
- `android-chrome-192x192.png` and `android-chrome-512x512.png`
- `mstile-150x150.png` and `browserconfig.xml`
- `safari-pinned-tab.svg`
- `site.webmanifest`

Theme color: `#070b24`
Accent color: `#6e56ff`
