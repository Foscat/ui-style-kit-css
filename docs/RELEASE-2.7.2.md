# v2.7.2 native select affordance patch

This compatible patch restores dropdown cues while retaining the 20 presets,
25 themes, public entrypoints, native popups and semantic namespaces.

## Corrections

Preset-layer semantic field background shorthands reset the native indicator's
image, size, position and repetition. The shared fallback restores the existing
public tokens above generic component paint. The reserved text gutter survives
compact preset padding. Retro Glass keeps its indicator above its recessed
material; Neo Noir keeps its browser-owned arrow without duplicate custom paint.
Tactile hardware arrows and Clay texture layers remain preset-owned.

## Focused evidence

Two individually selected Chromium cases passed. The first visits all 20 presets
in light, dark and contrast modes with native, canonical `.usk-select`, compatibility
`.ui-select` and prefixed controls. The second checks keyboard selection, disabled
and multiple-select semantics, and settled LTR/RTL positioning under reduced
motion. The selected original single/multiple source contract and new publication
authority case also passed. The three changed stylesheets pass focused lint.
Named-theme, Firefox, WebKit and whole-suite results are not claimed here.

The first shared fix exposed Y2K gutter reset and Retro Glass material precedence.
Generated alias tracing identified Neo Noir's reduced root specificity. Test-only
corrections distinguish repeating Clay texture from indicators, preserve Tactile's
hardware end cap, and await computed CSS settlement in a standards-mode fixture.

Gnomie visually inspected the candidate CSS on the retained actual installed SYS
catalog DOM at desktop and phone widths. Both catalog page-size and language
controls had bounded arrows without overflow. This diagnostic preview is separate
from published-package consumer qualification and hosted acceptance.

The owner authorized selected affected checks and prohibited CI/full suites for
this repair. The manual `publish-select-patch.yml` route is restricted to 2.7.2.
It requires a verified exact source commit, merged PR and STE-Adam's latest
approval of that head independently of the author. A trusted main controller is
retained before candidate checkout. It reproduces tracked generated assets, checks
package contents, packs without lifecycle hooks, uses the existing npm package-owner
credential and compares anonymous public npm bytes to its SHA-256/SHA-512 receipt.
The matching GitHub release includes that tarball and receipt. The built-in
repository token creates its tag/release without starting legacy CI publishers.
No tests, CI script, new secret, paid resource or application deployment is included.

Default historical publishers and package hooks remain unchanged. This route does
not assert their suites ran. This CSS repository has no configured jsdoc2md
generator. The new publisher has a [granular jsdoc2md reference](api/publish-select-patch.md), generated using the existing SYS workspace tool. Professional JSDoc-compatible comments, maintained documentation and
the normal build preserve the source/generated boundary. Tracked wiki changes do
not publish the hosted Wiki. SYS must qualify the actual published stable package
and its integrity before production.
